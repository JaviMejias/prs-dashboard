# PR Control Room — frontend-only architecture

Phase 0 documents the personal frontend-only architecture. It does not change
the React runtime or introduce a domain-layer pattern.

See `master-plan.md` for the complete plan. Supporting documents cover local
ownership, localStorage compatibility, simple Git-versioned rulepacks,
ReviewContext, portable JSON and optional machine metadata.

Out of scope: backend, users, accounts, OAuth, PostgreSQL, Web Push, Webhooks,
queues, server deployment, multi-user synchronization and application logic
changes.
